## 🌱 How I Write Code

- **Keep it simple:** readable code beats clever code (KISS)
- **One job per unit:** functions and classes do one thing well
- **Don't repeat yourself:** shared logic lives in one place (DRY)
- **Test it:** every fix gets a test that would have caught the bug
- **Document the why:** comments for tricky logic, meaningful commit messages
- **Refactor regularly:** leave code better than I found it
